# 电源地就近打孔（LCEDA-pcb-autofanout）使用说明

> 嘉立创EDA专业版扩展：自动为**电压/GND 网络**的焊盘打扇出过孔。
> 就近模式（过孔贴焊盘边界）与**盘中孔**模式（过孔直打焊盘中心）可选；直线方向优先，
> 间距预检查 + DRC 后校验双保险，新增违规自动回滚；真直插焊盘三重甄别自动跳过，
> 封装脏孔数据自动按贴片处理；0402 等小封装密集区自动回退小过孔。

【待补截图：打孔前后画布对比】

## 适用环境

- 嘉立创EDA专业版（EDA Pro / EasyEDA Pro）≥ 3.2.0，需在 **PCB 编辑器**中使用
- 板内焊盘需已分配网络（已导入网表/原理图更新到 PCB）
- 仅支持通孔（VIA）；盲埋孔暂不支持

## 30 秒上手

1. **安装**：扩展中心搜索「电源地就近打孔」安装；或下载 `.eext` 文件后，在
   EDA Pro 菜单「设置 → 扩展 → 扩展管理器 → 离线安装」导入并启用
2. **预览**：打开 PCB，菜单「电源地就近打孔 → 预览（不修改画布）」，
   查看将打孔的焊盘清单、方向、距离与线宽
3. **执行**：确认无误后点「一键打孔」；DRC 后校验通过即完成
4. **回退**：不满意时点「删除本插件创建的过孔/连线」，一键清理本次产物
   （不影响手工布线与既有过孔）

> 建议：首次使用先「预览」确认位置；默认参数适配 6mil 间距标准工艺，可按需在
> 「设置面板...」调整（改动即自动保存）。

## 两种打孔模式

| | 就近模式（默认） | 盘中孔模式（设置面板开启） |
| --- | --- | --- |
| 过孔位置 | 焊盘边界外贴边（阻焊开窗边缘优先） | 焊盘正中心 |
| 连线 | 自动连线，线宽 ≤ 焊盘尺寸 | 无连线 |
| 适用 | 常规电源/地扇出 | BGA/小封装降感、密间距走线 |
| 工艺要求 | 常规 | 建议树脂塞孔/电镀填孔，否则焊膏会漏 |
| 放不下时 | 主过孔 8 方向全阻塞 → 自动换 0.2/0.4 小过孔重试 | 焊盘装不下主过孔 → 自动换小过孔；仍不行回退就近模式 |

## 菜单说明

| 菜单 | 说明 |
| --- | --- |
| 一键打孔 | 提取板面 → 规划 → 写回 → DRC 后校验（新增违规自动整体回滚） |
| 预览（不修改画布） | 只输出打孔计划明细，含每个焊盘的方向/距离/线宽 |
| 删除本插件创建的过孔/连线 | 按创建记录清理，可反复使用 |
| 诊断：输出焊盘明细到控制台 | 每个电源/地焊盘的原始数据（层/孔径/阻焊/引脚数）与打孔去向，排查专用 |
| 设置面板... | 图形界面配置全部参数（改动即自动保存） |

## 参数说明（设置面板）

### 网络

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 包含地网络 | 开 | GND/AGND/PGND/GND1/GND_PLL 等词族 |
| 包含电源网络 | 开 | VCC/VDD/VBUS/VBAT/3V3/+5V/1V8/3.3V/-5V 等词族 |
| 追加自定义网络 | 空 | 逗号分隔，如 `MOTOR_VDD,AGND`，忽略大小写 |

### 过孔与位置

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 孔径 / 外径 | 0.3 / 0.6 mm | 主过孔尺寸 |
| 回退小过孔 孔径/外径 | 0.2 / 0.4 mm | 主过孔放不下时自动换小一号（0402 密集区常见）；外径填 0 关闭 |
| 盘中孔 | 关 | 过孔直打焊盘中心，无连线（建议配合塞孔/填孔工艺） |
| 就近边界用阻焊层 | 开 | 开=贴阻焊开窗边缘；关=贴焊盘铜皮边缘 |
| 额外伸出余量 | 0 mm | 0 = 间距规则允许范围内尽量贴边 |

### 连线

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 线宽 | 0.4 mm | 实际恒不超过焊盘尺寸；0 = 自动取 min(焊盘尺寸, 过孔外径) |

### 过滤与避让

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 忽略器件引脚阈值 | 32 | 超过的器件整体忽略，保护 BGA；LQFP48 可设 64 |
| 直插孔跳过判定 | 开 | 真直插跳过 + 脏孔自动按贴片（见下节）；关闭后带孔焊盘全部参与 |
| 安全间距 | 0.15 mm | 预检查间距，建议与设计规则一致（6mil 工艺即 0.15） |
| 阻塞外扩步数 | 3 | 理想位置被占时沿方向逐档外扩，每档一个过孔外径 |
| 重复打孔合并外扩 | 1 | 同网络既有过孔在邻域内则跳过，防重复 |
| DRC 后校验与回滚 | 开 | 创建后真实 DRC 复查，新增违规自动整体回滚 |
| 宽松模式 | 关 | 板子本身已有 DRC 违规时用：忽略间距预检查（仅防重叠）、
跳过连线通道检查与 DRC 后校验；能打尽打，可能引入新违规 |

## 直插与脏孔甄别（重点）

真直插焊盘（电解电容、接线端子等）本身就是通孔，插件会跳过不打。为防止封装库
残留的脏孔数据把贴片误判为直插（实测案例：整板 89 个贴片焊盘被误判），跳过判定
须**同时**通过三条物理校验，任一不满足自动按贴片照常打孔：

1. **多层判定**：真直插焊盘层必为多层（MULTI）；单层铜皮上的孔数据必是脏数据
2. **器件全孔共识**：真直插件的全部焊盘都带孔；只有部分带孔的是脏数据
3. **焊环完整**：孔径 + 0.3mm ≤ 焊盘长边

被纠正的焊盘会在报告中列出：`疑似直插误判已按贴片处理：N 个焊盘（C114-1、…）`。
仍有个别误判时，可临时关闭「直插孔跳过判定」或把「诊断」控制台输出反馈给作者。

## 常见问题

**Q：为什么有些焊盘没打孔？**
报告按器件列出了原因，对号入座：

| 原因 | 处理 |
| --- | --- |
| 引脚超限（如 LQFP48 > 32） | 调大「忽略器件引脚阈值」（LQFP48 设 64；BGA 建议保持默认） |
| 直插孔 | 真直插（三重甄别通过）属预期跳过；怀疑误判看「疑似直插误判」行或诊断输出 |
| 已有就近过孔 | 同网络过孔已在邻域内，防重复；可调小「合并外扩」 |
| 无有效位置 | 8 方向全阻塞：确认回退小过孔已开启；或增大外扩步数、减小过孔/间距；板子本身有 DRC 违规可开宽松模式 |

**Q：重复执行会打出重复的孔吗？**
不会。已打过/既有的同网络过孔在合并邻域内会自动跳过，可放心多次执行、分批推进。

**Q：0402 小封装总是打不上？**
主过孔 0.6mm 在 0402 密集区常塞不下，保持默认的回退小过孔（0.2/0.4mm）即可；
仍不行开宽松模式。盘中孔模式下 0402 会自动用小过孔直打中心。

**Q：DRC 后校验回滚了怎么办？**
说明按当前参数创建会产生新违规。增大安全间距/伸出余量，或分批执行定位冲突区域；
板子本身已有违规时用宽松模式（后校验自动跳过）。

**Q：盘中孔会不会影响焊接？**
过孔打在焊盘中心且未塞孔时，回流焊焊膏会从孔中流失造成空焊。请确认板厂支持
树脂塞孔/电镀填孔工艺后再使用该模式，或仅对底层/内层网络使用。

**Q：怎么撤销？**
「删除本插件创建的过孔/连线」清理历史全部产物；单次操作也可直接 Ctrl+Z。
